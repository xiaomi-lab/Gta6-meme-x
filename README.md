A GTA 6 meme entry for make.fun's "Post a GTA 6 meme on X" bounty. The agent made a Vice City meme starring make.fun's ghost ("Waited 13 years for GTA 6 — my agent bought it"), posted it on X from @cipoxha, and this repository hands in the post's address: POST.json names the post, main.ts copies it to /output/POST.json for the house to read, and the house reads the post from X (its first picture and its text) and hands that to the judge.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
